### Configuration

Before running the application, configure your local application settings.

1. Navigate to the `DataProcesingCapybara` project folder.
2. Copy `appsettings.example.json`.
3. Rename the copied file to `appsettings.json`.
4. Fill in your own configuration values, such as database credentials and API keys.
5. Run the application.

**Important:** Never commit your personal `appsettings.json` file to GitHub. Only commit changes to `appsettings.example.json` when the configuration structure changes.
